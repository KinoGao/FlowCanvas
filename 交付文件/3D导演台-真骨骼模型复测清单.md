# 3D 导演台 · 真骨骼模型复测清单

> 背景：用户指出 LibTV 导演台的人物是**带骨骼的 3D 模型**，而原实现只是球体+胶囊拼的几何体木偶。本次把人物升级为真实蒙皮骨骼模型（Three.js 官方 Xbot.glb，CC0）。

## 改动文件
- `web/src/app/(user)/canvas/[id]/canvas-client-page.tsx`
- `web/public/models/Xbot.glb`（新增资源，2.8MB）

## 复测步骤
1. `pnpm dev` 启动，打开任一画布 → 新建「导演台」节点 → 进入 3D 导演台。
2. **人物应是真实人形模型**（不再是乐高/胶囊木偶），默认站立、双臂自然垂落体侧。
3. 左侧栏「添加角色」→ 画布出现第二个骨骼角色；两个角色各自可独立拖拽、独立选中。
4. 右侧面板「姿势」滑块（头/脊柱/左臂/右臂/左腿/右腿）拖动 → 模型骨骼实时摆姿。
5. 切换角色 `type`（male/female/child/tall/short/heavy/slim）+ `scale` → 不同比例角色同框（对齐 LibTV 机甲 1.7× 卖点）。
6. 选中角色时，头/双手出现青色拖拽手柄，拖动可微调姿势。
7. 720° 全景、轨道旋转/缩放/平移、截图分镜、画幅比例 —— 仍正常（上一轮已修）。

## 已知待确认项（如本地看到异常，单点修改即可）
- **手臂/腿部方向**：±90° 基准角基于 Xbot 骨骼朝向推导。若手臂外翻或上举（而非垂落），翻转 `applyDirectorPose` 中 `lArm`/`rArm` 的 base 角符号（行 ≈4545-4548）。
- **姿势手柄位置**：头/双手手柄坐标为组局部近似值，可能需微调（行 ≈4554-4571）。
- **性能**：每次 pose/位置变更 `rebuildScene` 会重新 `SkeletonUtils.clone`；多角色拖拽若卡顿，可改为按 `characterId` 缓存 clone。

## 已修复：人物完全不可见（2026-07-08）
根因：误以为 Xbot 是厘米单位（把骨骼 translation 之和 177 当成天生高度），硬编码 `scale=0.01`，把本就正确的 1.81 单位蒙皮模型缩成 0.018 单位 → 不可见。
修复：删除硬编码缩放，改为加载时用 `SkinnedMesh.computeBoundingBox()`（套蒙皮）实测真实高度并归一化到 1.8 单位（`computeModelScale` + `cachedDirectorModelScale`）。同时修了 `frustumCulled`（避免缩放后被裁掉）与多材质 mesh 的材质处理。现在人物应正常显示。

## 替换默认模型（后续）
改 `DEFAULT_DIRECTOR_MODEL_URL` 常量指向任意 rigged humanoid GLB，并在 `applyDirectorPose` 按目标模型骨骼名调整映射（已保留 `mixamorig:*` 与通用别名 `Head/Spine/LeftArm...` 回退）。支持用户上传自定义 rigged 模型时同理。
