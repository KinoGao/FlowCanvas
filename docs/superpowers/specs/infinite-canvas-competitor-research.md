# 无限画布竞品调研与差距分析

> 调研时间：2026-07（公开网页与官方文档抓取，未登录实测）
> 证据口径：外部产品结论基于 web 抓取（unverified 级）；FlowCanvas 现状基于源码 read/grep（verified 级）。

## 1. 调研对象与结论摘要

| 产品 | 画布形态 | 与 FlowCanvas 的相关性 |
| --- | --- | --- |
| **LibTV**（哩布哩布） | 无限画布 + 节点工作流（最直接对标） | **最高**：脚本节点、分镜表、Slash 快捷、工作流打组保存模板 |
| **TapNow** | Creative OS：Agent + Apps + 画布（三角色），画布承载 Brief/素材/过程/交付物 | 高：Agent 协同画布、上下文持久化 |
| **可灵 AI** | 无画布，任务表单式工作台；分镜 = 模型内 Multi-Shot 提示词配置 | 低（无节点式画布） |
| **即梦 AI** | 有"智能画布"（图像/镜头迭代编辑式，AI 片场）；Agent 模式；故事创作（剧本→分镜→成片） | 中：Agent 模式、故事创作流程 |
| **Runway** | 无无限画布；时间轴 Studio（2026-06）+ 节点式 Workflows（2025-10） | 中：节点式流程编排 + 时间轴组合 |
| **Pika** | 无画布/故事板；单镜头 + scene extension（末帧延伸） | 低 |
| **Sora**（已关停 2026-03） | Storyboard 时间轴（按帧区间组织多段提示词） | 低（形态参考价值） |
| **Obsidian Canvas** | 无限画布，5 类卡片节点、有向连线带标签、开放 JSON Canvas 格式 | 中：连线模型、导航/缩放体系 |
| **tldraw** | 无限画布，13 种默认形状，media/bookmark/embed 节点范式 | 中：媒体节点能力 |
| **Excalidraw** | 无限画布、手绘风格、开放 .excalidraw JSON、PWA/协作 | 低 |
| **Miro** | 7000+ 模板 + AI 理解画布上下文 | 中：模板系统标杆 |
| **Napkin** | 文本驱动 AI 视觉画布（非 prompt 驱动） | 低 |

## 2. LibTV 能力全景（FlowCanvas 对标基线）

来源：aihub.cn 评测 + novatools + LibTV 官网（unverified 级，多源一致）。

1. **无限画布工作台**：文本/图片/视频/音频/脚本五类基础节点，自由连线，可打组保存、一键重复执行。
2. **脚本节点与分镜系统**：输入剧情/角色参考图 → 自动分镜脚本 → 一键批量转分镜图 → 批量转视频片段，全程单条可调。
3. **Slash 快捷功能**（图像生成器内输入 `/`）：多机位九宫格、25 宫格连贯分镜、剧情推演四宫格、角色三视图、画面推演等专业分镜工具。
4. **图像工具集**：增强（2/4/6 倍放大）、扩图、多角度（15 环绕点位）、打光（26 主光点位+智能）、重绘、擦除、抠图、宫格切分、标注、裁剪（10 项）。
5. **视频工具集**：高清放大（2/4/6 倍）、帧率提升（30/60/90fps）、分镜解析、片段裁取。
6. **多模型接入**：图像 Seedream 5.0 / Midjourney V7 等；视频可灵 3.0 / Wan 2.6 / Seedance 1.5 / Hailuo / Vidu 等 20+。
7. **Agent 调用接口**：OpenClaw Skill 包，自然语言驱动从剧本到成片全流程。
8. 社区分享/发布（商业化，FlowCanvas v1 不做）。

## 3. TapNow Creative OS 关键洞察

- **三角色架构**：Agent（理解目标+调度任务）、Apps（服务具体创作场景）、画布（保存 Brief/参考素材/制作过程/不同版本/交付文件）。
- **上下文持久化**：资料进入画布后一直留在上下文中，不需要重复粘贴 Brief。
- **从已有工作开始**：连接 Lark/Notion/Slack App 读取客户 Brief、会议纪要、品牌规范。
- **对 FlowCanvas 的启发**：Agent 面板应读取当前画布上下文（已放置节点）作为生成输入——对应 AGENTS.md 第 12 节"后端代理执行模型请求"，Agent 与画布协同是本项目 canvas-agent 的差异化方向。

## 5. 通用画布产品值得借鉴项（低优先级参考）

- **连线语义化**（Obsidian）：连线可加标签/改色/端点重连 → 可用于"角色/场景/道具"关系标注。
- **导航体系**（Obsidian）：Zoom to fit / Zoom to selection / Reset zoom 快捷键（Shift+1/Shift+2）。
- **媒体节点范式**（tldraw）：image 裁剪/翻转、video autoplay、bookmark 元数据卡片、embed iframe。
- **模板系统**（Miro）：预置"分镜表/角色设定/场景/故事线"模板一键铺节点骨架。
- **开放数据格式**（Excalidraw/Obsidian）：画布数据用开放 JSON 结构，为跨画布复制与导入导出打基础。

## 6. 结论与实现建议（按 AGENTS.md 第 9 节顺序）

1. **分镜表视图**（衔接已有脚本工作台）：把脚本 beat 预览升级为可编辑的"分镜表"表格（序号/景别/时长/画面描述/台词/生成按钮），对齐 LibTV 分镜表形态。已有 scriptBeats 数据结构与 buildScriptBeats，改动集中于脚本工作台 UI。
2. **Slash 快捷命令面板**（最高优先缺口）：画布内输入 `/` 弹出命令面板，提供九宫格、25 宫格、四宫格、剧情推演、镜头聚焦、焦点编辑、角色三视图、画面推演等快捷入口，选中脚本/文本节点后批量创建分镜节点（复用 buildScriptBeats + createScriptStoryboard 机制，但按九宫格/宫格模板组织）。
3. **工作流模板**：把选中节点组（含连线）保存为模板 → 工具箱复用，持久化到后端账号工作区。
4. **跨画布复制（带连线）**：剪贴板/内存暂存复制节点组+连线，粘贴到另一画布。
5. **时间轴视频合成**：视频合成节点的编排入口升级为可视化时间轴。

> 实现顺序：1→2 为 AGENTS.md 优先项，建议先落地；3/4/5 按序推进。所有新增能力登记回 AGENTS.md 第 9 节。
