## 1. 调研对象与画布范式谱系

**关键结论：无限画布 + 节点工作流范式在主流商业平台只有三家**（LibTV、TapNow、献丑AI）；其余主流平台均为"单次生成器"或"API 层管线"，不在同一赛道。

| 产品 | 画布形态 | 与 FlowCanvas 相关性 |
| --- | --- | --- |
| **LibTV**（哩布哩布） | 无限画布 + 节点工作流，脚本→分镜→成片全流程，双入口（人+Agent） | **最高**（AGENTS.md 已锁定对标基线） |
| **TapNow**（添科智能） | Creative OS：Agent + Apps + 画布，节点类型含文字/图片/视频/音频/3D/播放列表 | **高**（画布协同最完整的参考形态） |
| **献丑AI**（xianchou.com） | 开源社区 + 创作工作台 + 画布工作流，统一积分 | 中（社区形态，商业化 v1 不做） |
| 即梦（Dreamina） | 单次文生图/文生视频 + "智能画布"入口（性质未核实）+ Agent 模式 | 低（无节点工作流） |
| 可灵（Kling） | 单次生成器；storyboard 是模型叙事能力（VIDEO 3.0）非画布 UI | 低 |
| Runway | Creative 多模型工作区 + Dev Workflows（**API 层**管线）+ Create with Agent | 中（工作流形态在 API 层，非画布 UI） |
| Vidu / Pika / Luma / Leonardo | 单次生成器（Pika/Luma 有 Agent 入口，无画布节点编排） | 低 |
| Obsidian Canvas / tldraw / Miro | 通用无限画布（无 AI 生成编排） | 低（连线模型/模板系统有借鉴价值） |

> 证据：LibTV（liblib.tv / aihub.cn / novatools）；TapNow（docs.tapnow.ai 13 个 zh 文档页 + 官网，见 §3）；献丑AI（xianchou.com）；即梦（jimeng.jianying.com 200 抓取）；可灵（klingai.com/global 200 抓取）；Runway（runway.com 200 抓取）；Vidu（vidu.com 200 抓取）；Pika（pika.art 200 抓取）；Luma（lumalabs.ai 200 抓取）；Leonardo（docs.leonardo.ai 200 抓取）。

## 2. LibTV 能力全景（对标基线）

来源：aihub.cn + novatools + LibTV 官网（unverified 级，多源一致）。

1. **无限画布工作台**：文本/图片/视频/音频/脚本五类基础节点，自由连线，可打组保存、一键重复执行。
2. **脚本节点与分镜系统**：输入剧情/角色参考图 → 自动分镜脚本 → 一键批量转分镜图 → 批量转视频片段，全程单条可调。
3. **Slash 快捷功能**（图像生成器内 `/`）：多机位九宫格、25 宫格连贯分镜、剧情推演四宫格、角色三视图、画面推演、镜头聚焦、焦点编辑等。
4. **图像工具集**：增强（2/4/6 倍）、扩图、多角度（15 环绕点位）、打光（26 主光点位）、重绘、擦除、抠图、宫格切分、标注、裁剪。
5. **视频工具集**：高清放大、帧率提升、分镜解析、片段裁取。
6. **多模型接入**：图像 Seedream 5.0 等；视频可灵 3.0 / Wan 2.6 / Seedance 2.0 / Hailuo / Vidu 等 20+（Seedance 2.0 经火山方舟 Agent Plan）。
7. **Agent 调用接口**：LibTV CLI / Skill 包，自然语言驱动全流程。
8. 社区分享/发布（商业化，FlowCanvas v1 不做）。

## 3. TapNow Creative OS 功能矩阵（本轮新增深挖）

来源：docs.tapnow.ai/zh 13 个文档页 + 官网首页（web_fetch 200，unverified 级）。

- **三角色架构**：Agent（读上下文/拆任务/调 Apps）、Apps（创作场景服务，可连 Slack/Lark/Notion 读 Brief）、画布（持久化 Brief/素材/过程/版本/交付物）。
- **节点与连线**：节点类型=文字/图片/视频/音频/3D 世界/播放列表；连线=参考引用关系（非执行顺序）；下游节点 `@` 引用上游图片；类型不兼容不连线；删除连线不删内容。
- **素材管理三级体系**：素材库（单条素材，个人/团队空间，文件夹/搜索/重命名）；**主体库**（同人物/产品/角色的一组参考→可复用主体，生成时 @ 主体保持外观一致，Seedance 2.0 参考模式）；模板（可复用节点连线结构，公共模板+我的模板，节点组形式加入不替换现有内容）。
- **播放列表 = 时间轴视频合成**：多个视频节点接入同一时间线，调整镜头顺序、拖边缘裁切、播放头切割（快捷键 C/Q/E）、预览、导出（原始 MP4 / 合并 MP4 / 回画布）；原视频节点不被覆盖。
- **视频编辑**：剪辑（时间轴出入点）、**智能剪辑**（画面变化自动识别镜头切换→拆成独立视频节点）、截帧（当前/首/尾帧→图片节点）。
- **图片影视级功能**：多机位九宫格（3×3 景别一致）、多角度（水平旋转/垂直角度/远近/广角）、重绘（对象替换）、打光（主光方向/亮度/色温/轮廓光）、扩图、擦除、标注、增强、抠图、快速切分。
- **Brainstorm 头脑风暴**：生成前创意开发入口，产出创意简报/剧本/分镜表/HTML Demo/Pitch Deck；支持影视拆解与镜头研究。
- **生成模式**：自动生成（Agent 连续执行，适合已验证流程）vs 手动确认（先出确认卡片：模型/比例/时长/数量/参考，用户确认才消耗积分）。
- **3D 世界节点**：搭建空间/摆内容/调相机，导入 .glb，构图后带回画布。

> 注：「AI 执行导演」「多角度镜头控制」等营销术语未在官方文档出现；可确认的对应能力为图片多角度/多机位九宫格/视频多镜头模式/智能剪辑。

## 5. 对标评估结论

**FlowCanvas 当前能力 ≈ LibTV 上线初期至中期的"创作工作台"形态，处于画布工作流赛道第三梯队的头部。**

- 相对 **LibTV**：核心创作流已对齐——基础节点、脚本分镜、分镜表、快捷分镜（4/9/25 宫格）、工作流模板（项目内）、跨画布复制、多模型、本地 Agent。未对齐项集中在快捷分镜的**专业工具**（镜头聚焦/焦点编辑/角色三视图/画面推演）与**视频生产链路**（时间轴合成）。
- 相对 **TapNow**：差距最大的是**生产链路闭环**三件套——播放列表时间轴、主体库（角色一致性）、智能剪辑；其次是素材三级体系与 Brainstorm。TapNow 的"连线=引用关系、@ 上游引用、生成模式确认"设计可作为 FlowCanvas 后续交互参考。
- 相对 **即梦/可灵/Runway/Vidu/Pika/Luma/Leonardo**：范式不同赛道（单次生成器 vs 画布工作流），不构成直接对标；Runway Dev Workflows 与可灵 storyboard control 属 API/模型层能力，仅作能力清单对照。
- **差异化优势**：开源自托管 + 本地 Canvas Agent（MCP）+ 后端模型注册中心，与行业 Agent 化趋势（即梦 Agent 模式/Pika Agent/Luma agents/Runway Create with Agent）同向，且 Agent 与画布深度协同（节点即上下文）目前无直接竞品。

## 6. 实现建议（按 AGENTS.md 第 9 节表顺序）

1. **快捷分镜补全**（#4）：镜头聚焦、焦点编辑、角色三视图、画面推演——复用节点浮动菜单与 buildScriptBeats/createScriptStoryboard 机制。
2. **账号级工作流模板持久化**（#5）：工具箱模板从项目内升级为后端账号工作区持久化（backend Workflow 模板 API + 前端模板库）。
3. **时间轴视频合成**（#6）：视频合成编排入口升级为可视化时间轴——多片段拼接/裁切/排序/导出，对齐 TapNow 播放列表交互（顺序调整/边缘裁切/播放头切割/导出合并）。
4. **脚本富文本文档编辑**（#3）：脚本节点编辑器升级为富文本（标题/段落/台词/分镜标注）。
5. **项目级工作流/故事板切换 + 全局素材引用视图**：多画布组织与素材全局引用查看。
6. **主画布整理/连线显隐**：画布视图切换、连线显示开关。
