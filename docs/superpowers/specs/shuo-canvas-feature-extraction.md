# SHUO Canvas v0.7.9 与 FlowCanvas 画布能力对比

> 分析对象：`D:\SHUO Canvas`（Electron 打包产物，`resources/app/src` 保留了前端源码）。
> 原则：只提取功能与交互概念，不直接复制 SHUO Canvas 的源码、二进制资产、VIP/积分/商业逻辑或第三方模型绑定。

## 1. 参考产品核心优势

### 1.1 节点类型

SHUO Canvas 的节点类型明显比当前 FlowCanvas 多，可划分为四组：

- 素材源节点：源文本、源图片、源视频、源音频。
- AI 生成节点：AI 文本、AI 图片、AI 视频、AI 音频。
- 功能节点：注释、白板、拼图、网页预览、网页参考卡片、场景检测、剪辑、调试。
- 内容工作台节点：分镜表、分镜脚本、3D 导演台、360 全景、人物替换、视频复刻。

### 1.2 节点级工具

图片节点工具最完整：

- 抠图 / 标注 / 裁剪 / 高清 / 扩图 / 宫格 / 多角度 / 主体识别 / 擦除 / 重绘 / 360 全景。

视频节点工具：

- 裁剪、抠像、擦除、高清、智能剪辑、关键帧提取、补帧、倒放、音画分离、换声、同步播放、全屏、下载。

音频节点工具：

- 裁剪、倍速、下载、语音工作室、音色克隆、音色转换、人声分离。

文本节点工具：

- 复制、全屏、Markdown 渲染。

### 1.3 画布交互与配置

- 可自定义快捷键：分组、搜索、冲突检测、预设切换。
- 节点管理面板：可固定在左侧 / 右侧 / 底部。
- 任务中心：批量生成队列、并发控制、暂停 / 取消 / 重试。
- 连接线样式：曲线、直角、直线。
- 连线悬停出现剪刀按钮，直接删除连线。
- 输入偏好：滚轮缩放 / 类 Figma 上下平移。
- 辅助线吸附、网格吸附、关联节点高亮、标题跟随缩放等开关。
- 节点自动避让、媒体尺寸重置、上传快捷键、文件拖入、右键上传。
- 多选框选、批量下载、画布截图、项目包导入导出。

### 1.4 高级工作台

- 剧本工作室：剧本导入、资产拆解、分镜生成、逐镜生成、视频合成。
- 人物替换工作室：检测框、姿态、裁剪、模型、音视频合成。
- 视频复刻工作室：视频拆分、提示词反推、片段生成。
- 3D 分镜导演台：场景、物体、摄像机、镜头、机位书签、截图。
- 语音工作室：本地识别、说话人分离、句子切割、克隆。
- 自定义 AI 应用 / RunningHub / ComfyUI / RH 工作流。
- 对象存储、项目版本、归档、诊断包。

## 2. FlowCanvas 已具备且不弱于 SHUO 的能力

FlowCanvas 在 Web + Spring Boot 架构下已经实现了不少上游没有重点做的能力：

| 能力 | FlowCanvas 现状 |
| --- | --- |
| 无限画布 + 节点连线 | LeaferJS 自研画布，已完成 |
| 五大基础生成节点 | 文本 / 图片 / 视频 / 音频 / 脚本 |
| 工作流节点 | 生成配置、ComfyUI、智能剪辑、导演台、360 场景 |
| Composer | 模型、参考图、风格、相机、主体、运镜、快捷分镜 |
| 批量生成 | 宫格、批量图片、批量脚本导出 |
| 工作流执行 | 组执行、连通节点拓扑执行、Agent Run 服务端任务 |
| 素材引用 | 连接引用、@ 标签、参考缩略图 chip |
| 跨画布复制 | 内存剪贴板，可选包含连线 |
| 媒体持久化 | 后端账号工作区、storageKey、签名 URL、缩略图 |
| Agent | 在线 + 本地 Canvas Agent、Codex MCP、画布 Ops |
| 脚本 | 幕 / 场 / 镜拆解、分镜表、逐镜生成、工作台 |
| 时间轴 | 多片段裁剪、音频轨、混音、MediaRecorder 合成 |
| 性能 | 空间索引、背景 pattern、Leafer 命令式视口、媒体暖启动 |

建议不要把 SHUO Canvas 中已经不如 FlowCanvas 的部分搬回来，例如：

- 纯本地文件保存：FlowCanvas 已决策以后端账号工作区为权威。
- 积分、会员、CDKEY、VIP 模型门禁：不属于 v1 单机开源定位。
- 人物替换 / 视频复刻等强依赖特定厂商积分接口的商业工作台：需要先确认模型协议与付费边界。

## 3. 抽取价值与实施难度

### P0：低成本、高价值，建议下一批实施

| 功能 | 说明 | 预计改动 |
| --- | --- | --- |
| 连接线样式 | 曲线 / 直角 / 直线，按项目或账号持久化 | 化学连接几何 + 设置项，约 1-2 个 PR |
| 连线悬停剪刀 | 悬停显示删除按钮，保留右键菜单 | Leafer 连接命中层 + hover UI |
| 节点自动避让 | 新建 / Agent 创建节点时避免重叠 | 复用现有空间索引，改动较小 |
| 注释节点 | 轻量便签 / 批注节点，支持标题与备注 | 新增节点类型 + 渲染，风险可控 |
| 多选批量下载 | 批量导出选中媒体 | 复用现有下载链路 |
| 节点管理面板 | 按节点类型筛选、搜索、定位、显隐 | 可复用资产面板，界面增量 |
| 快捷键配置搜索 | 当前已有快捷键，补搜索与冲突检测 | 全局设置面板增量 |

### P1：中成本，需要先做产品决策

- 白板节点：画笔、矩形、橡皮、油漆桶、背景图、图层变换。
- 拼图节点：1×1 到 5×5 自定义宫格、拖拽图片、导出拼图。
- 网页预览节点：输入 URL / 搜索内容，在画布内浏览并抓取文本图片。
- 网页参考卡片：保存网页引用、标题、摘要、缩略图。
- 视频低阶工具：帧提取、关键帧、倒放、音画分离、换声、同步播放。
- 音频低阶工具：裁剪、倍速、人声分离、音色库。
- 项目归档 / 版本历史 / 项目包：当前部分能力已有，可补版本与归档。
- 输入偏好：鼠标滚轮方向、类 Figma 滚轮选项。

### P2：高成本 / 需要外部能力

- 视频高清 / 补帧：需要模型注册中心新增视频编辑、放大、插帧协议。
- 视频抠像、擦除、智能剪辑：需要支持 mask、关键帧的模型或本地 FFmpeg 管线。
- 人物替换工作室、视频复刻工作室：需要专用模型、付费协议和大量工作台 UI。
- 3D 分镜导演台：当前已有 Three.js 导演台，可继续补机位书签、角色姿态、场景素材库。
- 对象存储：FlowCanvas 单实例后端账号存储已满足当前定位；多对象存储属于部署能力。
- 自定义 AI 应用聚合：当前以模型注册中心 + ComfyUI 为主，建议保持现有架构。

## 4. 建议的实施顺序

1. 先做画布基础体验：连接线样式、连线剪刀、节点自动避让。
2. 再做组织与批量效率：注释节点、节点管理、多选批量下载。
3. 再做可配置性：快捷键搜索与冲突检测、输入偏好、工具栏位置。
4. 最后评估进阶工作台：白板、拼图、网页引用和本地媒体工具。

> 当前进度：P0 首批 7 项已实现待测试；P1 中不依赖外部模型/付费协议的能力（输入偏好、音频裁剪/变速、白板、网页预览/引用卡、拼图、视频倒放、音轨提取、关键帧批量导出、多视频同步预览、节点管理面板左右停靠、主工具栏底部/左侧/右侧停靠、项目版本快照）也已实现待测试，详见 `docs/content/docs/progress/pending-test.mdx`。剩余 P1/P2 需要产品决策或外部模型/付费协议支持。

推荐首轮直接实施第 1 组和第 2 组；第 3 组和第 4 组需要确认是否纳入本次优化范围。

## 5. 边界

- 不复制 SHUO Canvas 的二进制、打包资源或第三方模型适配代码。
- FlowCanvas 不引入积分、会员、CDKEY 等商业能力。
- 所有新功能仍走后端账号工作区，不新增浏览器本地业务存储。
- 需要付费模型或外部工作流的工具，必须先确认协议和成本边界后再接入。
