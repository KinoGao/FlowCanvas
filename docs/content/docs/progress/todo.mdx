- 画布状态 store 多实例串扰隐患：`useCanvasStore`、`useCanvasUiStore`、`useCanvasAgentStore` 目前都是模块级 zustand 单例。单页渲染单画布时彼此不串扰（节点拖拽等瞬时交互状态已内化到 `leafer-canvas.tsx` 组件内，不依赖模块级 store）；但当未来支持多 tab / 多个 `Canvas` 同时挂载 / 窗口分屏预览时，这些共享 store 中按画布或 UI 维度持有的状态会跨实例叠加。启用多画布前需优先修复：将其重构为 React Context Provider 形式（每个 `<CanvasProvider>` 持有独立 store 实例），或在 store 内加入 `scopeKey` 字段做画布隔离。
