## 工作流整组执行

- 节点悬浮工具栏新增「整组执行」（Play 图标），打组节点选中后的组操作条也新增「整组执行」按钮。执行范围：起点属于某个打组时执行该组成员，否则沿连线收集与当前节点相连通的整组节点；按连线拓扑序逐层重跑组内生成节点（图片/视频/音频/带 prompt 的文本/ComfyUI），同层互不依赖的节点并发执行，单个节点失败会跳过其下游并在结束消息中汇总成功/失败/跳过数量。需要确认：打组后点击「整组执行」按上游先行顺序重跑且下游拿到上游最新结果；未打组时对连通分量执行；纯手写文本、上传素材、配置节点不会被触发；某节点失败时依赖它的节点被跳过并有明确提示；执行中重复点击会被拦截。

## 画布崩溃恢复提示
- 编辑过程中仅为当前账号和画布写入极小的恢复标记，异常退出后下次进入会显示「已恢复上次未完成编辑的最近保存状态」；实际画布数据仍只从后端账号工作区加载，正常隐藏页面或离开画布时会在现有 flush 后清除标记。需要确认：编辑后强制关闭浏览器再打开同一画布会显示提示且节点/连线为最近自动保存状态；正常切换页面、刷新或关闭画布后再次进入不显示提示；不同账号和不同画布互不影响。

## 画布空间索引接线

## 安全与可靠性加固

- **ComfyUI 代理 SSRF 修复**：未登录的 `/api/comfyui-proxy?path=/view` 媒体读取不再接受客户端传入的 `baseUrl`，只允许访问配置的 `COMFYUI_BASE_URL`（未配置时回退 127.0.0.1:8188）；已登录用户不受影响。需要确认：未登录时用自定义 baseUrl 访问 `/view` 被拒绝；登录后 ComfyUI 面板的媒体预览 / 任务提交 / 上传均正常；未配置 COMFYUI_BASE_URL 的本地部署行为不变。
- **模型运行时鉴权收紧**：`/api/model-runtime/models/` 与 `/api/model-runtime/providers/` 仅 GET（浏览器媒体加载）公开，POST 模型调用必须登录。需要确认：未登录调用模型接口返回 401；画布生成（图片/视频/音频/文本）登录后正常；`<img>`/`<video>` 直接加载生成媒体仍无需登录。
- **默认凭证恢复硬编码（内部部署）**：`AUTH_CODE` 默认 `gycode`、`ADMIN_CODE` 默认 `admincode`、`MEDIA_SIGNING_SECRET` 默认继承 `ADMIN_CODE`（均可通过环境变量覆盖），不再随机生成。需要确认：不设置任何环境变量时注册（authCode=gycode）与管理后台登录（adminCode=admincode）均可用；设置环境变量后覆盖生效；Compose 部署开箱即用（不再强制要求三个环境变量）。
- **docker-compose 凭证**：两个 compose 文件默认使用硬编码凭证，可通过环境变量覆盖。需要确认：直接 `docker compose up -d` 可拉起；后端镜像由 CI 一并构建（tag `v*` 同时产出前端与后端镜像）。
- **任务去重锁修复**：同用户同任务 ID 的并发请求不再绕过去重（锁对象引用计数）。需要确认：视频生成任务重复提交（如快速双击）只创建一个任务；并发轮询任务状态不产生重复生成。
- **上游请求重定向关闭**：模型适配器（OpenAI 通用 / Agnes / Seedance）不再跟随 3xx 重定向，代理错误统一返回脱敏文案。需要确认：正常模型调用不受影响；上游返回 5xx/超时时前端提示为通用错误信息。
- **媒体下载响应加固**：`/api/user/files/...` 响应增加 `X-Content-Type-Options: nosniff`，contentType 白名单（image/video/audio/pdf/json/octet-stream/text）之外的按 `attachment` 下载返回。需要确认：画布图片/视频/音频节点显示正常；上传非白名单类型文件后下载行为符合预期。
- **机位面板崩溃修复**：摄像机属性面板的 hooks 顺序违规（选中机位失效后再选中会触发 React "Rendered more hooks" 崩溃）已修复。需要确认：删除当前机位后再选中其他机位，右侧面板正常；机位属性编辑、截图、发送到画布功能正常。
- **Director 拖拽性能**：机位/角色变换拖拽期间不再每帧执行全量状态深拷贝、JSON 比较与 localStorage 写入（批量结束时统一落盘一次）。需要确认：拖拽机位或角色位置时画面流畅无卡顿；拖拽结束后刷新页面变换结果保留；撤销（Ctrl+Z）行为与之前一致。
- **选择同步防抖**：画布节点选择状态未变化时不再触发 React 重渲染。需要确认：框选/点选/连选节点行为与之前一致；选中态高亮正常。

## OpenAI 图片响应格式

- OpenAI 兼容图片模型现在会把“生图响应格式 = URL”明确发送为 `response_format: "url"`，文生图、参考图生图和 multipart 图片编辑不再仅仅省略 `b64_json` 后回退到厂商默认值；返回的 `data[].url` 继续由现有图片响应解析器接收。需要确认 Junli 等默认返回 Base64 的中转服务在选择 URL 后实际返回临时媒体地址，并验证 Base64、自动模式和 Seedream 输出格式不受影响。

## Agnes 参考图兼容

- Agnes 图生视频上传的参考图会在后端生成独立的兼容副本：最长边限制为 2048px、透明背景合成为白色，并编码为不超过 5MB 的 JPEG；画布素材原图和其他模型的参考图处理保持不变。需要使用原先触发 `image URL could not be downloaded or did not return a valid supported image` 的大尺寸图片重新生成，确认 Agnes 能创建任务并正常返回视频。

## Seedream Runtime Contract

- Seedream 5.0 Pro now declares one output, up to 10 reference images, 1K/2K and interactive editing. Seedream 5.0 Lite, 4.5 and 4.0 declare up to 14 reference images, a 15-image combined input/output ceiling, and sequential image generation. For those group-image models, one selected output sends `sequential_image_generation: "disabled"`; two or more selected outputs send `auto` with `max_images`. Confirm the published runtime capability response, the Composer choices, and actual vendor responses with the configured Volcengine account.

## Video Result Storage

- Generated video and audio files now bypass the JSON/data-URL upload route and use multipart storage directly. This avoids the 20MB JSON parser ceiling and the base64 expansion that could add an avoidable failed upload after a provider task had already completed. Confirm with a generated video larger than 15MB that it reaches its node, remains playable after reopening the canvas, and no JSON-size warning is written by the backend.

- Resuming a persisted video task now always performs one provider status lookup before enforcing the local 30-minute deadline. A completed provider task can therefore still be restored after the canvas was closed; a task that is still queued or running after the deadline is ended as before. If the provider result is ready but saving it to the account media library fails, the task ID is retained for the next canvas open instead of submitting and charging for another generation.

- 视频任务创建请求现在必须在 90 秒内返回任务 ID，Agnes、Seedance 和通用 OpenAI 视频协议的后端适配器使用相同上限；任务创建成功后的轮询、恢复和最终媒体下载仍沿用原有 30 分钟生成窗口。需要分别确认上游不可达时能在 90 秒左右明确失败，以及正常创建后长时间排队的任务不会被创建超时误杀。

## Model Protocol Catalog

- The administrator model drawer now selects a backend-provided calling protocol instead of typing a free-form adapter name. OpenAI direct, Gemini, Agnes Video V2, and Seedance 1.0/1.5/2.0 Ark task protocols are listed from the registered backend adapters. Adding a model should only require selecting one of these protocols plus its capabilities; a truly new vendor HTTP contract still needs one new adapter, which then appears in the selector automatically. Confirm the catalog loads in `/admin`, existing model protocol values are retained, and saving/verifying a model uses the selected protocol.

- Seedance 1.0 Lite runtime entries now use the Seedance task adapter rather than the generic OpenAI video path. The adapter also permits explicitly disabled unsupported flags such as `watermark: false`; only an unsupported enabled feature is rejected. Confirm Lite text-to-video and image-to-video create a task, reach a terminal state, and do not fail before task creation because of disabled audio, watermark, or draft fields.

- Official Seedance model IDs now reapply their authoritative protocol and capability template when runtime configuration is loaded, even if an older saved model contains an empty capability object or the generic `openai` adapter. Confirm existing Seedance 2.0 configurations publish as `seedance-v2` without requiring the administrator to recreate the model.

## Leafer Canvas Interaction Engine

- Leafer 拖动和连线仍按动画帧直接更新视觉位置，React 节点状态改为约 10fps 同步并在松手时强制提交最终位置；未选中的 DOM 节点保持挂载，同时允许浏览器跳过视口外绘制。需要在 100 个以上节点的画布中确认拖动连续、连线不脱离、松手后位置准确且媒体不会重新请求。
- 已有画布恢复遮罩会等待当前视口内的图片在 Leafer 中解码完成或明确失败后再淡出，最长等待 4 秒；相同后端媒体的并发签名 URL 请求会合并为一次。需要确认刷新后不再出现空节点闪烁、同一素材不再重复请求签名接口，并验证坏图不会永久阻塞画布。
