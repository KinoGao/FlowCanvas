## 全部连线流光质感与悬空创建菜单

- 所有正式连线和临时拉线统一为连续冷银灰细线底轨；正式连线仅在鼠标悬停时叠加蓝色发光短段，鼠标移出后立即恢复为普通静态线，选中节点、关联节点或选中连线均不会自动播放流光；临时拉线始终保留流光，流速沿用当前人工调定值。
- 动画复用 Leafer 单一 `requestAnimationFrame` 循环，以约 30fps 批量更新路径偏移，不触发 React 每帧重渲染；系统开启“减少动态效果”时保留静态蓝色光段。
- 临时连线落在空白处后，“引用该节点生成”菜单支持点击外部、点击其他节点、点击画布空白处或按 Esc 取消；取消时菜单与悬空线同步清除，菜单内部操作不受外部点击监听影响。
- 需要确认：画布静止且鼠标未经过连线时，全部正式连线只有银灰底轨；悬停任意连线时仅该线显示蓝色流光，移出后消失；从节点端口拉线时临时线保持流光；点击画布空白处后菜单和悬空线均消失。

## 画布 Agent 能力重写（全能力操作层）

- Agent 操作层（ops）从 8 种扩展到 22 种，在线 Agent（网站模式）新增 14 个工具、本地 MCP Agent（本机模式）新增 13 个工具，两个 Agent 共用同一执行层：

  - 图像：`canvas_image_edit`（多角度/扩图/打光/抠图/720° 全景）、`canvas_image_quick_command`（镜头聚焦/焦点编辑/电影级光影/角色三视图/画面推演）、`canvas_image_process`（本地裁剪/宫格切分/高清放大，不耗模型）；
  - 视频：`canvas_video_analyze`（抽帧拆分镜表）、`canvas_video_trim`（出入点剪辑）、`canvas_video_compose`（多片段拼接合成，可指定片段出入点）；
  - 组织复用：`canvas_group_nodes` / `canvas_ungroup_nodes`、`canvas_save_template` / `canvas_insert_template` / `canvas_list_templates`（仅在线）、`canvas_grid_storyboard`（脚本节点拆四宫格/九宫格/25 宫格分镜）。
