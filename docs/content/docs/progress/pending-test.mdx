## 画布 Agent 任务规划模式（Agent Run）

- 画布创作 Agent 面板新增「对话操作 / 任务规划」模式切换（Composer 上方 Segmented）。任务规划模式对齐 VOZEB Agent Run 模型：一次 function call 输出完整创作计划（创作简报 + 视觉方向 + 产物清单 deliverables，含依赖关系与原位编辑 targetNodeId），渠道不支持工具调用时回退解析裸 JSON。
- 计划经确认卡（计划摘要 + 产物列表 + 开始执行/取消）确认后，由编译器 `compileAgentRunOps` 确定性生成画布 ops：简报/视觉方向文本节点 + 任务节点列（幂等节点 id：agentrun-{runId}-{deliverableId}），自动连线（简报/方向→任务、依赖任务间串联）；产物提示词注入简报与视觉方向约束保证一致性。
- **服务端执行**（新增 `agent_runs` 表 + `/api/agent-runs` 接口 + `AgentRunExecutor`）：确认后任务交给后端按依赖拓扑执行（并发 2），经模型代理自调用完成生成（文本/图片/音频同步、视频创建任务后轮询下载，复用全部协议适配器），产物落盘为用户文件；**页面关闭后任务继续在服务端跑**。支持暂停（停止派发新任务）/继续/取消/单任务重试；进程重启后视频任务按上游任务 id 续取，同步任务标失败可重试。
- 前端轮询 run 状态并把任务结果回填画布节点（completed → 写入 storageKey/内容，failed → 标错误）；重开画布自动恢复轮询与结果回填。
- 需要确认：任务规划模式出计划卡 → 开始执行后服务端跑完整流程、关闭页面再打开进度与结果仍在；任务按依赖顺序执行；暂停/继续/取消/重试正确；对话操作模式不变。注意：执行生成会消耗模型额度；服务端执行要求使用注册中心模型（本地自定义渠道暂不支持）。

## 分镜表幕/场/镜结构化识别与导出改进

- 本地解析器识别剧本正文里明确写出的分镜表结构：`◆ 第一幕「探测」· 约 30 分钟` 幕/集/章行、`场 1 · A 控制室 · 深夜` 场行、`SH1 大远景 拉远：画面。（台词：…）` 镜行（SH/SC/镜 编号），产出完整分镜（不截断）并保留幕归属、场标题、景别、运镜、台词；正文无镜行编号时仍走原来的行切分兜底。
- 脚本工作台新增「按正文重拆」按钮：正文含镜行编号时可一键本地重建分镜表与幕结构，不消耗模型；分镜表幕内按「场」显示场标题行；幕归属匹配容错（归一化/前缀匹配，「第一幕」可对应「第一幕《探测」」）。

## 画布图片节点「裁剪」弹窗交互修复

- 修复锁定比例（locked）逻辑错误：原实现在锁定时取宽高像素最大值同时赋给宽高，把裁剪框变成正方形；在 16:9 等非正方形图片上拖动任意手柄，高度会被 clamp 到 1（整图高度）、y 被压到 0，裁剪框瞬间撑满。现改为按拖动前的像素宽高比保持比例，以主导方向（e/w 以宽度、n/s 以高度）联动缩放，越界时在边界内收缩且比例不破坏。
- 修复越界跳变：拖 e/s 手柄放大到超出画布时，原实现先 clamp 宽度再 clamp x（`clamp(x, 0, 1-width)`），导致 x 被强制回退、裁剪框整体左移/上移跳动；现改为固定对边（e 保持左边缘、w 保持右边缘、s 保持上边缘、n 保持下边缘），越界时限制尺寸而非移动位置。
- 裁剪几何计算抽为 `canvas-crop-geometry.ts` 纯函数（moveCrop / resizeCrop），新增 7 个单测覆盖锁定比例、越界、最小尺寸、平移边界。
- 需要确认：图片节点「裁剪」弹窗中，自由比例下拖 e 手柄到右边界时裁剪框右边缘应被挡住且框不跳动；锁定比例后拖 e/s/w/n/对角手柄，裁剪框比例保持与锁定前一致、不越界；重置、平移、确认裁剪结果与框选一致。
