# 待测试
- 后台管理长内容滚动：管理后台改为独立的全视口纵向滚动容器，模型配置、ComfyUI、工作流和账号画布内容超过屏幕高度时可以继续向下滚动，并为页面底部保留操作空间。需要确认桌面和窄屏下最后一项配置、保存按钮及各标签页内容均可访问。
- 画布生成等待动效替换：生成中节点使用静态点阵、局部点亮遮罩与双向淡入淡出柔光，替代原有单向扫光。需要确认图片、视频、音频和文本节点在生成等待、画布缩放及节点拖拽时动画正常，生成完成后动效及时消失。
- 后台全局模型注册中心与管理员权限：管理员先配置厂商名称、接口地址、API Key、协议和模型列表路径，再拉取上游模型并逐个分类为文本、图像或视频。文本模型可配置纯文本与识图/多模态；图像模型可配置文生图、图生图、图像编辑、画质、1K/2K/4K、比例和 1/2/4 张数量；视频模型可配置文生视频、全能参考、图生视频、首尾帧、图片参考、智能多帧、有声、水印、草稿、时长、分辨率、数量和引用上限。创作端只接收稳定模型 ID 与对应类别能力，请求由后端映射到私有 `requestModel` 并再次校验。需要确认：OpenAI 兼容和 Gemini 协议均能拉取模型；同一厂商可混合配置三类模型；切换分类时不会遗留无关能力；Agnes、Seedance、可灵等模型只显示和接受各自支持的参数；`/api/runtime-config` 不泄露 API Key、真实地址或 `requestModel`；普通账号不能访问管理接口。
- 上传图片进入 360 全景预览：图片节点只保存本地或后端 `storageKey`、没有内联 `content` 时，点击节点工具栏“360视图”会完成标记并立即进入沉浸式预览；已标记图片再次点击也会直接打开。三击图片进入预览的手势继续保留。需要确认本地图片、后端账号图片均可进入，左键旋转、滚轮调整 FOV、截图插入画布正常，普通图片三击查看不受影响。
- 拖出连接线后的固定预览：从节点左侧或右侧连接点拖到画布空白处并松开时，临时 SVG 连接线会保留在松开位置，线长和方向不再随之后的鼠标移动变化；画布缩放或平移后仍锚定原画布坐标，并与节点创建菜单保持同步。按 Esc、关闭菜单、连接到已有节点或创建新节点后会清除临时线。需要确认：源端口和目标端口都可正常使用，连续取消/创建不会留下残线，也不会触发画布拖拽或 `Maximum update depth exceeded`。
- LibTV 连接点 / 连接线 / 导演台细节对齐：连接点应固定在节点左右边缘中点，节点边缘显示 LibTV 式小加号，连接线 hover 时出现短暂流光，选中时出现持续流光；拖拽新连接线时也应从对应左右端口出发。连接线靠近有效目标端口 48px 范围时会吸附到端口中心并高亮候选端口，已吸附后移动到 64px 外才解除，正向 source -> target 与反向 target -> source 均可使用。导演台摄像机和角色属性面板都应提供左/右/上/下/前/后 6 向移动按钮，角色面板继续保留头部、躯干、左右臂、左右腿骨骼姿势控制。需要确认缩放、拖拽节点、hover 连接线、选中连接线、正反向端口吸附、打开导演台、调整角色/机位位置后都没有 `Maximum update depth exceeded`。
