# 本地开发

FlowCanvas 前后端分离：`web/` 是 Vite + React 前端，`backend/` 是 Spring Boot 后端。

## 1. 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端默认运行在 `http://localhost:9801`，数据库文件默认 `./data/app.db`。首次启动会自动建表。

## 2. 启动前端

```bash
cd web
pnpm install   # 或 bun install
pnpm dev
```

前端默认运行在 `http://localhost:9800`。开发模式由 Vite 配置把 `/api/*` 代理到后端 `9801`。

## 3. 数据库与初始凭证

- 使用 `AUTH_CODE` 注册账号、`ADMIN_CODE` 登录管理后台；内部部署默认值为 `gycode` / `admincode`，可通过环境变量覆盖。
- 首次使用需在后台登记模型厂商与 API Key。

## 目录与常见改法

- 前端 API 客户端：`web/src/services/api/`（按域分文件：`image` / `video` / `audio` / `prompts` / `comfyui` / `backend` 等）
- 全局业务状态：`web/src/stores/`
- 画布实现：`web/src/app/(user)/canvas/`
- 后端接口：`backend/src/main/java/com/infinitecanvas/backend/controller/`
- 后端业务逻辑：`backend/src/main/java/com/infinitecanvas/backend/service/`
- 数据访问：`backend/src/main/java/com/infinitecanvas/backend/repository/`
- 文档站内容：`docs/content/docs/`

## 检查与测试

```bash
cd web && npx tsc --noEmit   # 前端类型检查
cd web && npx vitest run     # 前端单测
cd backend && mvn compile    # 后端编译
```
