# 后端账号保存隔离

账号保存模式下，前端画布项目和素材的 `id` 只作为业务数据 ID，保存在 `project_json` / `asset_json` 中。

后端数据库表 `canvas_projects.id` 和 `assets.id` 使用内部记录 ID。新记录按当前 `user_id + 前端业务 id` 生成，避免两个账号导入同一个本地画布或素材时互相覆盖。

读取数据时，后端仍返回原始 JSON，因此前端看到的项目 ID、素材 ID、节点连接关系保持不变。
