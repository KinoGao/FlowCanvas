# 代理（转发）系统

## 概述

所有对外转发统一由后端 Spring Boot 承担，前端只请求后端的 `/api/*` 路径（开发由 Vite 代理，生产由反向代理同域）。前端不直连第三方第三方模型接口，私有 API Key 不会下发到浏览器。

| 代理 | 后端路径 | 用途 |
|---|---|---|
| AI 代理 | `/api/ai-proxy` | 转发上游 AI 返回的远程媒体 URL 等资源 |
| 模型调用 | `/api/model-runtime/models/{modelId}/**` | 文本 / 图片 / 视频 / 音频模型调用 |
| ComfyUI 代理 | `/api/comfyui-proxy` | ComfyUI 工作流提交、上传与媒体输出 |

---

## AI 代理

### 工作原理

前端在需要读取上游返回的远程 URL 时，把 URL 改写为 `/api/ai-proxy?target=<encodedUrl>` 走后端透传。前端实现见 `web/src/lib/ai-proxy-url.ts`。

### 服务端实现

`backend/src/main/java/com/infinitecanvas/backend/controller/AiProxyController.java`：

- 透传任意 `target`，支持 GET / POST / PUT / DELETE
- 转发 `Authorization`、`Content-Type`、`Accept`、`Range` 等请求头
- 默认 10 分钟超时
- **SSRF 防护**：未登录请求（浏览器媒体加载）拒绝解析到内网 / 环回 / 链路本地 / 组播等地址；已登录用户允许内网目标（本地模型服务等）
- 上游超时返回 `502`，网络异常统一返回「上游请求失败」，不向客户端透出主机 / 端口 / 内网地址等细节

前端调用 `rewriteThroughProxy(url)`（`web/src/lib/ai-proxy-url.ts`）把远程媒体 URL 改写为 `/api/ai-proxy?target=...`；`image.ts`、`video.ts` 等在解析上游返回的图片 / 视频 URL 时使用它。

## 模型运行时代理

### 服务端实现

`backend/src/main/java/com/infinitecanvas/backend/controller/ModelRuntimeProxyController.java` 挂载在 `/api/model-runtime/models/{modelId}/**`：

- POST 模型调用必须登录；未登录调用返回 `401`
- 仅 GET（浏览器签名媒体加载）对未登录公开
- 每个模型由对应的 `ModelRequestAdapter` 适配（Generic OpenAI / Gemini / Agnes Video / Seedance 等）

### 前端

模型请求构造与能力读取见 `web/src/services/api/model-capabilities.ts`、`image.ts`、`video.ts`、`audio.ts` 等。

## ComfyUI 代理

### 服务端实现

`backend/src/main/java/com/infinitecanvas/backend/controller/ComfyUiProxyController.java` 挂载在 `/api/comfyui-proxy`：

- **路径白名单**：`/system_stats`、`/object_info`、`/prompt`、`/history/`、`/view`、`/upload/image`
- GET：媒体读取走 `HttpClient`（不跟随重定向），透传 `Range` 等媒体请求头、返回媒体响应头
- POST（JSON）：提交 `/prompt` 等，支持 `X-FlowCanvas-Job-Id` 去重
- POST（multipart）：上传图片到 `/upload/image`，内存限制 16MB
- 目标地址来自配置的 ComfyUI 地址（未配置回退 `127.0.0.1:8188`）；**未登录的 `/view` 媒体读取不允许客户端传入 `baseUrl`**，防止 SSRF
- 上游超时 / 网络错误统一返回 `{ "detail": ... }` 脱敏文案

### 前端

`web/src/services/api/comfyui.ts` 提供任务提交、上传与列表查询；载荷 / 媒体请求头带 `durableGenerationHeaders`（生成任务持久化）。

---

## 安全要点

- 所有代理统一由后端执行，浏览器不持有厂商 API Key。
- AI 代理与 ComfyUI `/view` 均针对未登录请求做了 SSRF 防护（拒绝内网目标，或禁止客户端传入目标地址）。
- 上游错误脱敏返回，不向浏览器暴露内网 / 上游地址细节。
