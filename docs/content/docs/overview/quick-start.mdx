# 快速开始

FlowCanvas 由前端（Vite + React，端口 `9800`）和后端（Spring Boot + SQLite，端口 `9801`）两部分组成。画布、素材、媒体和生成记录保存在后端账号工作区，模型厂商/API Key 由后端统一管理。

## 本地启动

### 1. 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端默认运行在 `http://localhost:9801`。可通过环境变量覆盖：

- `PORT`：后端端口，默认 `9801`
- `DB_PATH`：SQLite 数据库文件，默认 `./data/app.db`
- `AUTH_CODE`：注册鉴权码，默认内部部署值 `gycode`
- `ADMIN_CODE`：管理员授权码，默认 `admincode`
- `MEDIA_SIGNING_SECRET`：媒体访问签名密钥，默认继承 `ADMIN_CODE`

### 2. 启动前端

```bash
cd web
pnpm install   # 或 bun install
pnpm dev
```

前端默认运行在 `http://localhost:9800`，开发模式下由 Vite 将 `/api/*` 代理到后端 `9801`。

## 首次使用

1. 打开 `http://localhost:9800`，用注册鉴权码 `gycode` 注册账号并登录。
2. 进入后台管理（`/admin`，用管理员授权码 `admincode`）登记模型厂商地址、API Key、模型 ID 与能力选项。
3. 回到画布创建节点开始创作。AI 请求经由后端代理执行，不会把私有 API Key 下发到浏览器。

## Docker 启动

使用发布镜像：

```bash
docker compose up -d
```

前端 `9800` 与后端 `9801` 会一并拉起，后端数据卷挂载到 `./data`。生产部署前请配置环境变量覆盖默认凭证。

本地构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```
