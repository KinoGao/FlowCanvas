# 功能介绍

本文档记录当前项目已经实现的主要功能。

## 画布项目

- 支持创建多个画布项目。
- 支持项目重命名、删除、批量选择和批量删除。
- 支持单个画布项目导出为 JSON，也支持从 JSON 导入画布。
- 画布项目保存在后端账号工作区，登录后自动保存，多端访问同一账号数据一致。

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆和重置视图。
- 支持小地图定位，可开关小地图。
- 支持点阵、网格线、空白三种背景。
- 支持浅色和深色主题。
- 支持框选、多选、全选、取消选择、删除选中。
- 支持复制粘贴节点和节点之间的连线。
- 支持撤销和重做节点、连线、视口、背景和助手会话变化。
- 支持节点连线，并高亮当前节点相关的上下游节点和连线。
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片。

## 节点

画布支持以下基础节点：

- 图片节点：展示上传图片、生成图片或我的素材图片。
- 文本节点：保存提示词、说明文案、AI 文字回答等文本内容。
- 视频节点：展示上传或生成的视频。
- 音频节点：展示上传或生成的音频。
- ComfyUI 节点：选择 ComfyUI 工作流并绑定上游节点输入。
- 脚本、导演台、视频合成和分组作为专用创作节点提供。

节点支持：

- 拖拽移动。
- 四角缩放。
- 图片节点等比缩放或自由比例切换。
- 查看节点基础信息和 JSON。
- 删除、复制、粘贴。
- 通过左右连接点建立上下游关系。
- 按类型自动编号，双击节点顶部名称可重命名。
- Composer 和 ComfyUI 输入条按连线建立顺序展示文本、图片、视频和音频引用。

## 图片工作流

- 支持上传图片到新节点。
- 支持拖拽图片文件到画布。
- 支持替换已有图片节点内容。
- 支持下载图片节点。
- 支持把图片节点保存到“我的素材”。
- 支持图片裁剪，并把裁剪结果生成为新的图片节点。
- 支持本地多角度变换，并把结果生成为新的图片节点。
- 支持生成失败后重试。
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果并设置主图。

## AI 生成

项目默认由后端代理执行 AI 请求：模型厂商地址、API Key 和模型由后端全局模型注册中心统一管理，密钥不下发到浏览器，创作端只读取脱敏后的运行时模型目录，请求经后端 `ModelRuntimeProxyController` 转发到上游适配器。

上游返回的远程媒体 URL 由后端 AI 代理统一处理：图片 / 视频节点加载时把远程 URL 改写为 `/api/ai-proxy?target=...` 透传，代理执行带 SSRF 防护，不会把内网地址或上游细节暴露给浏览器。

OpenAI 兼容图像和文本能力继续复用现有接口：

- `/v1/images/generations`：文生图。
- `/v1/images/edits`：图生图/参考图编辑。
- `/v1/responses`：文本问答、带图问答和在线 Agent 工具调用。
- `/v1/models`：读取 OpenAI 兼容厂商的模型列表。

视频能力使用后台已注册的调用协议：

- OpenAI 风格视频：`POST /v1/videos`、`GET /v1/videos/{id}`、`GET /v1/videos/{id}/content`。
- Agnes Video V2 与 Junli Studio 等专用异步协议由对应后端适配器转换创建、轮询和下载请求。

Base URL 如果已经以 `/v1` 或 `/api/v3` 结尾，系统不会再追加 `/v1`。

配置弹窗里的“拉取模型列表”会真实请求厂商模型目录，不会为未注册协议伪造模型结果。

可配置项：

- Base URL。
- API Key。
- 默认模型。
- 图片质量。
- 图片比例。
- 生成数量。
- 视频模型。
- 视频比例、清晰度、时长、生成声音和水印。
- 视频模型能力由后端 `app.model-capabilities.video` 统一配置，Composer 只展示当前模型真正支持并会进入请求的生成模式和参数。

普通图片、文本、视频和音频节点可以直接在 Composer 中输入提示词生成结果。ComfyUI 节点独立选择工作流并读取上游节点输入；输入条会按连线建立顺序展示引用。历史画布中的生成配置节点仍可继续读取和运行，但新建入口不再创建该节点类型。

视频生成可从文本节点读取 prompt，从图片节点读取参考图；参考视频、参考音频和各项参数是否可用，以后台发布的模型能力和所选调用协议为准。生成成功后会把视频插入画布为视频节点并使用原生播放器预览。

## 画布助手

画布右侧助手面板支持：

- 文本问答。
- 生图。
- 读取当前选中节点作为引用。
- 自动把选中节点的上游节点也纳入引用。
- 粘贴图片到助手输入框并插入画布。
- 历史会话。
- 删除单条或多条会话。
- 重试回答。
- 把助手生成的文本插入画布。
- 把助手生成的图片插入画布。
- 折叠和展开助手面板。

## 提示词库

前台提示词库支持：

- 按标题搜索。
- 按标签筛选。
- 按来源筛选。
- 查看提示词详情。
- 查看封面和结果图。
- 复制提示词。
- 把提示词加入“我的素材”。

提示词管理支持：

- 查询提示词。
- 按分组和标签筛选。
- 查看远程提示词源。
- 触发读取内置远程提示词源。

内置远程提示词源由后端拉取并通过 `/api/prompts` 提供给前台。

## 素材

“我的素材”保存在后端账号工作区，支持：

- 新增文本素材和图片素材。
- 编辑素材标题、封面、标签、来源、备注和内容。
- 删除素材。
- 按关键词搜索。
- 按类型筛选。
- 分页浏览。
- 复制文本素材。
- 下载图片素材。
- 从提示词库和画布节点加入素材。
- 在画布中插入素材。

## 配置和同步

- 项目需要登录：注册码、管理员授权码由后端环境变量控制（内部部署默认 `gycode` / `admincode`）。
- 后台管理（`/admin`）统一维护模型厂商地址、API Key、模型 ID 与能力选项；创作端只读取脱敏后的运行时模型目录。
- 画布、素材、媒体和生成记录保存在后端账号工作区，按账号自动保存；不同账号互不影响。

## 当前限制

- AI API Key 由后端集中管理，密钥不会下发到浏览器；未登录访问 AI 接口返回 `401`。
- 未登录状态仅允许浏览器直接加载已签名的生成媒体，其他业务接口需要登录。
- 参考视频、参考音频与远程结果 URL 的支持范围取决于当前注册的模型协议；不支持的素材类型会在提交前提示移除或切换协议。
- 画布更适合桌面端使用，移动端触控体验还未系统完善。
